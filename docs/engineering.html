Problem / thesis

Spacious ambient reverb without hand-waving

Build a portable C++20 late-reverb foundation that can survive realtime constraints, then bind it to AUv3 with explicit lifecycle and parameter contracts — while recording what is measured versus what is still open.

Product intent lives in the charter; existence claims live in source and testing.md. An accepted ADR authorizes design, not automatic implementation.

Hard parts

Where correctness is expensive

Realtime numerical safety

Denormals, cessation bounds, and whole-path fault detection with next-block recovery — NS cases and DS-propagated bounds recorded before claiming the stereo path closed.

Parameter bridging

Control-thread mailbox and reset-flag design (ADR-008) keep host events off the audio thread’s critical path; PB-1…PB-8 are mechanism checks, not host proof.

Hybrid bypass

T_silence-bounded hybrid bypass merges dry passthrough with DSP lifecycle so mute/unmute does not leave stale energy — implementation exists; HT matrix still open.

Measurement contracts

DS-1…13 cover energy, echo density, decay, coherence, mono compatibility, magnitude response, determinism, and cost — sonic acceptance closed for DS-B without rewriting architecture.

Decision discipline

Selected ADR highlights

ADR-001

Portable core

CMake/C++20 DSP core without host headers in the hot path — host binding is a separate layer.

ADR-002/003

Late network + numerical safety

Fixed FDN topology and damping/decay/denormal contracts that bound what “safe silence” means.

ADR-006

Diffusion / stereo baseline

Evaluation architecture for diffusion and stereo taps; Tasks 1–4 measured; sonic acceptance closed without forced redesign.

ADR-008–010

Bridge, bus, lifecycle

Parameter mailbox, production bus policy, and device lifecycle matrix before wrapper expansion.

ADR-012

Host/device catalog

HT-1…12 methodology exists as a catalog; execution remains the open acceptance gate.

Delivery system

Agentic method without cosplay

Models accelerate drafting and mechanical verification. Ownership stays with the human who accepts ADRs, authorizes plans, and refuses status claims that outrun disk evidence.

Provenance for milestones is recorded in agent-log.md and commit messages — useful for process honesty, not a public brand roster.
