Agentic engineering practice

Human-gated, evidence-driven delivery

Multi-agent coding is the delivery system — not the product brand. Written contracts first; independent re-verification from disk before anything is called done.

Decide

ADRs lock topology, safety, parameters, bus policy, and acceptance catalogs before code expands scope.

Plan

Interface-level milestone plans name tests, non-goals, and owner gates — authorization is separate from design acceptance.

Implement

Bounded increments against the plan: portable DSP, then bridge, then AUv3 lifecycle — no silent scope creep.

Verify

Independent re-derivation of evidence: CTest suites, measurement contracts, listening rounds, Sol-level architecture review when warranted.

The owner remains the gate for product claims and architectural revision. Agent roles are execution metadata recorded in the agent log — they are not part of the public brand or navigation.
